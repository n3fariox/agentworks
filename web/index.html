External controllers

Named credentials for MCP clients outside Agentworks, such as a coordinating conversation. Each is limited to this project and its own grants, never acts as a session, and is attributed in agent activity. Revoking takes effect on the next request.

Service restart and completion reports are never available to controllers. Their messages do not wake sessions.

Contains the secret token. Store it privately; revoke and recreate the controller if it is exposed.
